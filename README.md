# ZeroWasteTable

A web app to keep leftover food from going to waste. Restaurants log stock and expiry, list surplus for buyers, or donate cooked food to NGOs.

## How to run

You need Node.js installed.

```bash
git clone https://github.com/Manajain20/ZeroWasteTable.git
cd ZeroWasteTable
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## What it does

- Restaurant, buyer, and NGO each get their own flow
- Inventory with expiry tags
- List leftover food for pickup, or offer cooked food as a donation
- Data is saved in the browser (`localStorage`) for this first version
